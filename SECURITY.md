# Security

Please report security issues privately, not in a public issue.

Use GitHub's private vulnerability reporting: on the repository's main page, open the **Security** tab
(labelled "Security and quality" in GitHub's current layout) and click **Report a vulnerability**.

Examples: a credential, a private hostname or other private data that has appeared in an issue, a pull request or
a commit.

This private route is for security matters only. Conduct reports, platform access offers and vendors' replies to
results have their own routes (GOVERNANCE.md, "Contact").
