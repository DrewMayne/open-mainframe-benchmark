# Governance

- **Maintainer:** Andrew Mayne. The maintainer decides on spec changes and merges, after public discussion in issues.
- **Spec changes:** proposed as issues or pull requests and recorded in the spec's version history. Any result names the spec version it used.
- **Results:** anyone may publish results from this kit, if they include the manifest and raw output and name the spec version. Results that don't follow the run rules must say so.
- **Independence:** no vendor approves or vetoes results. Support from any party is disclosed in full.
- **Future:** if the project gains contributors from more than one organisation, it may seek a neutral home (for example the Open Mainframe Project).
